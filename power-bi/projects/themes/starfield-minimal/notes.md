# Starfield Minimal (Dark) — design notes

Generated by [`../_build-space-themes.py`](../_build-space-themes.py). Edit the spec there and re-run;
do not hand-edit `starfield-minimal-v1.0.json`.

## Intent

The void with nothing added. Near-black canvas (`#08090C`), silver-forward series, and exactly one
saturated accent (ion blue) plus one warm signal (amber). Colour appears only where it carries
meaning, so a highlighted series actually reads as highlighted.

Pick this when the report is dense or the audience is analytical — Deep Space's jewel tones start to
compete with each other past about six visuals on a page; this one doesn't.

| 2 | `#B6BDCA` | silver — the default "everything else" series |
| 3 | `#E6A34A` | signal amber — the "partial / caution" signal |
| 4 | `#6E7787` | slate — same hue as `neutral` |
| 5 | `#86C6E8` | pale cyan |
| 6 | `#566486` | indigo slate — lifted from a deeper slate to clear 3:1 on the card surface |

Surfaces: card `#111318` · void `#08090C` · deeper `#1A1D24` · hairline `#262A33`.

## Mission-status mapping (space dataset)

| MissionStatus | Colour | Source |
|---|---|---|
| Success | `#57B98A` | theme `good` |
| Partial Failure | `#E6A34A` | `dataColors[2]` — no theme key exists for "warn" |
| Failure | `#DB5F5F` | theme `bad` |
| Prelaunch Failure | `#6E7787` | theme `neutral` |

Note the semantic trio here is deliberately *outside* the series palette — in a minimal theme,
status colour should look different from category colour, not blend into it.

`RocketStatus` (Active / Retired): Active → `#5B9BF5` ion blue, Retired → `#B6BDCA` silver.

## Contrast

Audited to WCAG AA (4.5:1 text) and 3:1 (data fills) on every build. Slot 6 was raised from the
originally-sketched deep slate specifically to pass the 3:1 fill check (it now sits at 3.15:1).
