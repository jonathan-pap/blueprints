## Intent

A long-exposure telescope frame. Near-black **indigo** void (`#070B18`) rather than neutral black —
the blue cast keeps it from looking like an unstyled dark mode, and it lets the cyan/violet accents
read as emission rather than as UI chrome. Starlight text (`#E8ECF8`) at 10.3:1 on the card surface.

The default of the four space themes: enough hues for a many-series launch-cadence chart, dramatic
enough to carry a space subject, still legible at dashboard density.

## Mission-status mapping (space dataset)

`MissionStatus` has four states but Power BI's theme has only `good` / `neutral` / `bad`. Use the
theme keys for the three that map cleanly and the amber data colour for the fourth:

| MissionStatus | Colour | Source |
|---|---|---|
| Success | `#2DC7A6` | theme `good` |
| Partial Failure | `#F2A93B` | `dataColors[2]` — no theme key exists for "warn" |
| Failure | `#E0555F` | theme `bad` |
| Prelaunch Failure | `#7C87A6` | theme `neutral` |

Conditional-formatting measures returning the strings `"good"` / `"bad"` / `"neutral"` pick up the
theme keys automatically. The Partial Failure amber has to be a literal hex in the measure.

`RocketStatus` (Active / Retired): Active → `dataColors[0]` ion cyan, Retired → `neutral`.

## Contrast

`_build-space-themes.py` audits every text pair to WCAG AA (4.5:1) and every data fill to 3:1
against the card surface on each run. This theme passes with no exceptions.
