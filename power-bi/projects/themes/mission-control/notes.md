# Mission Control (Dark) — design notes

Generated by [`../_build-space-themes.py`](../_build-space-themes.py). Edit the spec there and re-run;
do not hand-edit `mission-control-v1.0.json`.

## Intent

A flight-ops console rather than the sky. Graphite panels with a faint green cast (`#141A18`),
phosphor-screen text (`#DCE8E2`), and a palette borrowed from status lamps: green = nominal,
amber = caution, red = alert. Utilitarian on purpose — it reads as instrumentation, not as art.

Six colours only. An ops board that needs more than six categories is usually the wrong chart.

## Palette roles

| Slot | Hex | Role |
|---|---|---|
| 1 | `#4FD98A` | phosphor green — hero series, `accent`, same hue as `good` |
| 2 | `#E8B33C` | caution amber — the "partial / degraded" signal |
| 3 | `#3FC2D6` | CRT cyan |
| 4 | `#E05C4E` | alert red — same hue as `bad` |
| 5 | `#5B87D9` | telemetry blue |
| 6 | `#8A968F` | tape grey — same hue as `neutral`, for inactive/retired |

Surfaces: panel `#141A18` · console `#0C0F0E` · deeper `#1E2724` · bezel `#2A3833`.

## Mission-status mapping (space dataset)

| MissionStatus | Colour | Source |
|---|---|---|
| Success | `#4FD98A` | theme `good` |
| Partial Failure | `#E8B33C` | `dataColors[1]` — no theme key exists for "warn" |
| Failure | `#E05C4E` | theme `bad` |
| Prelaunch Failure | `#8A968F` | theme `neutral` |

This is the theme where that mapping is most native — the palette was picked from the status-lamp
convention in the first place, so a status-coloured chart and a category-coloured chart agree.

`RocketStatus` (Active / Retired): Active → `#4FD98A`, Retired → `neutral` tape grey.

## Caveat

Green-as-hero plus red-as-alert is the one red/green pairing the colour system guidance warns about
(`02-build/theme/create/color-system.md`). It is deliberate here — the lamp convention is the point —
but for a report where deuteranopia matters, pick **Deep Space** or **Starfield Minimal** instead.

## Contrast

Audited to WCAG AA (4.5:1 text) and 3:1 (data fills) on every build. Passes with no exceptions.
